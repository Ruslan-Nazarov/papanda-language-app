## Скачать и установить (Android)

1. Открой **[последний релиз](https://github.com/ruslan-nazarov/papanda-language-app/releases/latest)** и скачай `papanda.apk` из раздела Assets.
2. Открой скачанный файл на телефоне.
3. Android спросит разрешение ставить приложения из этого источника — разреши.
4. Появится предупреждение Play Protect («Неизвестное приложение») — нажми **Подробнее → Всё равно установить**.

Подробная инструкция с картинками по шагам — в [docs/tester-install.md](docs/tester-install.md).

Приложение пока не в Google Play (закрытое тестирование требует 20 тестеров × 14 дней),
поэтому ставится напрямую файлом — это нормально и безопасно, Android просто
предупреждает про любые приложения не из Маркета.

## Что внутри

- **Разбор предложений** — главное в papanda. Предложение раскладывается по членам
  (сказуемое → подлежащее → дополнение → …), а внутри слов показываются части,
  которые несут смысл (морфемы).
- **Слова** — одно слово на всех твоих языках сразу, рядом.
- **Узнавание слов** — быстрая проверка «помню / не помню», с приоритетом слов,
  которые пора повторить.
- **Статистика** — индекс запоминания (iMW) и график по дням.

Изучаемые языки: английский, итальянский, испанский, немецкий, французский,
казахский, латынь. ИИ (Gemini/Cerebras/Groq через собственный прокси) генерирует
новые предложения под твой словарь; без интернета/прокси работает на встроенном
наборе примеров.

## Технологии

React Native (Expo, SDK 54), Zustand для состояния, Cloudflare Worker как прокси
для AI-запросов (ключи провайдера не покидают сервер).

## Разработка

```bash
npm install
npx expo start
```

Тесты: `npx tsx --test tests/*.test.ts`. Типы: `npx tsc --noEmit`.

Сборка Android APK (через EAS):

```bash
npx eas-cli build -p android --profile preview
```
