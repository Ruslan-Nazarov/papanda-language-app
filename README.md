## Скачать и установить (Android)

1. Скачай **[papanda.apk — 1.3.0, Android build 22](https://expo.dev/artifacts/eas/rDq5uGUxTFQk2-dcnzl0xG5EZSe6gb5tlzJfQPmDHRw.apk)** — тестовая сборка от 21 октября 2026 со встроенной книгой и обновлёнными объяснениями. [Страница сборки](https://expo.dev/accounts/runaz/projects/papanda-app/builds/ac5fed96-5e12-419e-b8c6-59dc8b1d452c). Все сборки: [expo.dev/.../builds](https://expo.dev/accounts/runaz/projects/papanda-app/builds).
2. Открой скачанный файл на телефоне.
3. Android спросит разрешение ставить приложения из этого источника — разреши.
4. Если Android или Play Protect блокирует установку, проверь источник и сведения о сборке перед продолжением.

Подробная инструкция с картинками по шагам — в [docs/tester-install.md](docs/tester-install.md).

Приложение распространяется как тестовый APK. Указанная сборка включает книгу и связанный с ней разбор предложений.

## Что внутри

В версии 1.3.0 встроена авторская книга: все семь языковых разделов, введение и общая схема — 66 материалов без интернета. Открыть: **Разбор предложений → Книга и метод**. Есть поиск, закладки, продолжение чтения, мобильные таблицы и переходы между правилами и практикой. Пояснение ИИ получает реальные выдержки из книги со ссылками на источник. [Подробности и сценарии проверки](docs/book-in-app-2026-10-21.md).

В сборке 22 объяснение сначала показывает, как устроена конкретная фраза. Подробный разбор слов и окончаний и список книжных источников раскрываются отдельно.

- **Разбор предложений** — главное в papanda. Предложение раскладывается по членам
  (сказуемое → подлежащее → дополнение → …), а внутри слов показываются части,
  которые несут смысл (морфемы).
- **Слова** — одно слово на всех твоих языках сразу, рядом.
- **Узнавание слов** — быстрая проверка «помню / не помню», с приоритетом слов,
  которые пора повторить.
- **Статистика** — индекс запоминания (iMW), график по дням и план повторения на сегодня.
- **Автономные карточки** — 210 встроенных предложений для всех семи языков.
- **Управление AI** — этапы генерации и отмена; закрытие окна объяснения останавливает запрос.
- **Резервные копии** — предпросмотр файла и локальный возврат к состоянию до импорта.
- **Мастерская предложения** — вход из тренажёра: самостоятельный выбор членов
  предложения, последовательные подсказки с грамматическими маркерами, цепочки
  развития мысли и одна мысль на семи языках. Встроенные примеры работают офлайн.
- **Свои тексты** — проверяемое деление абзаца на предложения, чтение по одному,
  разбор через ИИ по кнопке, сохранение позиции и готовых разборов в резервной копии.
- **Навыки разбора** — отдельно от словарного запаса: самостоятельные ответы,
  ответы с подсказкой, ошибки и подбор следующего упражнения по слабой роли.
  Спорный ответ можно исключить из статистики.

Изучаемые языки: английский, итальянский, испанский, немецкий, французский,
казахский, латынь. ИИ (Gemini/Cerebras/Groq через собственный прокси) генерирует
новые предложения под твой словарь; без интернета/прокси работает на встроенном
наборе примеров.

## Технологии

React Native (Expo, SDK 54), Zustand для состояния, Cloudflare Worker как прокси
для AI-запросов (ключи провайдера не покидают сервер).

## Разработка

```bash
npm install
npx expo start
```

Установите также зависимости прокси: `npm ci --prefix gemini-proxy`.
Установка применяет узкую совместимость Metro 54 с исправленным `image-size` 2.x через `scripts/patch-dependencies.cjs`; он также применяет локальные защитные правки трёх транзитивных библиотек. При обновлении Expo этот patch нужно пересмотреть.
Все тесты и типы приложения/прокси: `npm run check`.
Локальная сборка прокси без публикации: `npm run build --prefix gemini-proxy`.
Проверка web-интерфейса: задайте для тестовой сборки
`EXPO_PUBLIC_GEMINI_PROXY_URL=https://smoke.invalid/v1/generate`,
выполните `npx expo export --platform web --output-dir dist-audit`,
затем `node scripts/smoke-web.cjs` (внешние запросы в тесте блокируются).
Все девять UI-проверок на этой же сборке: `npm run check:ui`.
Команда проверяет первый запуск, основной интерфейс, мастерскую, книгу,
повторение, тренажёр, управление генерацией, ввод слов и туры карточек;
этот же набор запускается в CI. Отдельный экспорт для каждого сценария не нужен.
Первый запуск проверяется отдельно: `node scripts/smoke-onboarding.cjs`.
Проверка проходит вводные страницы кнопками и прокруткой, вход и пропуск, повторный запуск,
стабильность статистики без действий и смену языка на другой вкладке.
Проверка управления во время генерации: `node scripts/smoke-generation.cjs`.
Она задерживает каждый этап ИИ и проверяет кнопки карточки, все пять вкладок,
приоритет запроса выбранного слова и отмену при замедлении CPU в четыре раза.
Локальный замер обработки предложений со всем словарём:
`npx tsx scripts/benchmark-sentence-validation.ts` (без сети).
Новые учебные режимы проверяются командой `node scripts/smoke-workshop.cjs`:
экран 320px, скрытый перевод, подсказки, спорные ответы, свои тексты,
фиктивный AI-разбор, отмена, сохранение позиции и удаление с подтверждением.
Не используйте тестовую сборку с фиктивным URL для выпуска.
