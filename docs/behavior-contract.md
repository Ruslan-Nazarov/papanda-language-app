# Сохраняемое поведение Papanda

Этот список фиксирует поведение версии 1.3.1, которое легко случайно нарушить при изменении интерфейса. Изменение оформления само по себе не означает изменение упражнения.

## Тренажёр предложений

- Закрытые карточки раскрываются в установленном порядке: по грамматическим основам, начиная со сказуемого. Артикль раскрывается одновременно со связанным словом, в том числе при нажатии на любую из этих карточек. Артикли подлежащего и дополнения не объединяются в отдельный шаг. Итальянские местоимения, совпадающие по форме с артиклями, размечаются по функции в предложении: например, `La vedo` — дополнение, а `La ragazza` — артикль с существительным.
- После раскрытия всех карточек следующий шаг показывает перевод предложения; только затем доступен повтор с первого шага, который скрывает карточки и перевод. Тап по свободному месту области упражнения выполняет то же действие, что и кнопка «Разбор» / «Перевод» / «Повторить с 1 шага».
- Вторая и последующие части сложного предложения имеют двойную рамку **до раскрытия**. Закрытая рамка серая; открытая получает цвет роли. Это одинаково работает в карточках и таблице.
- Номера раскрытого разбора, цвета ролей, цветное деление на части, перевод, действия со словарём и переключение вида сохраняются.
- Сохранённые и отредактированные пользователем предложения доступны в обычной очереди вместе с ИИ. Свежая генерация заменяет встроенный резерв, но не пользовательские карточки.
- Основная очередь содержит самостоятельные разнообразные предложения: разные ситуации, участники, действия и конструкции. Генерация нарастающих цепочек включается только в мастерской; цепочки из кеша не попадают в основную очередь даже при отсутствии других ИИ-карточек.
- Фоновый ответ ИИ не должен менять открытую карточку или выбранный шаг нарастающего предложения.
- Мастерская доступна из меню тренажёра. В ней остаются самостоятельный разбор, нарастающее предложение, развитие мысли, сопоставление языков и чтение своего текста.
- Эксперимент «Занятия по 5 предложений» по умолчанию выключен. Его остановка возвращает обычный тренажёр и сохраняет начатое занятие. При повторном запуске сохраняются конкретный шаг, выбранные слова и проверенные ответы; обновление ИИ-кеша не меняет снимки предложений. Пропуски и спорные ответы не считаются самостоятельным успехом. Подробнее: [занятия](sentence-lessons.md).

## Слова, прогресс и книга

- Языковые заметки и черновики сохраняются отдельно от упражнений, входят в резервную копию и переживают очистку ИИ-кеша и сброс статистики. Исходные примеры сохраняются снимками. В тренажёре предложений нажатие на раскрытое слово открывает объяснение его формы в контексте: исходная форма, значимые части и причина выбора окончания или суффикса. Редактор словаря доступен отдельной кнопкой внутри; закрытие редактора возвращает к объяснению. Без подключения ИИ показывается сообщение о недоступности объяснения, редактор остаётся доступным. Подробнее: [заметки](notes.md).

- Стабильный ключ слова `eng` не меняется при редактировании отображаемого перевода.
- Редактирование, избранное, ассоциации, отложенные слова, история ответов и отмена ответа не должны терять чужие изменения или добавлять лишние показы.
- Ассоциация сохраняется при вводе; для её сохранения не требуется ответить или перейти к следующей карточке.
- Завершение тура не показывает лишнюю карточку. Возвращение на завершённый экран не начинает следующий тур автоматически.
- Изменение языков, импорт и сброс статистики отменяют устаревшие задания и историю текущей тренировки.
- Книга открывается из настроек. Сохраняются поиск, закладки, позиция чтения, размер текста, разделы главы и переходы к источникам из объяснений.
- Резервная копия включает пользовательские данные, настройки и состояние книги. Копии старого формата без книги не стирают её текущее состояние.
- Перед заменой прогресса сохраняется точка восстановления. Ошибка записи не считается успешным импортом; видимое состояние откатывается, несохранённые данные остаются доступны для повторной записи.
- Ошибка чтения хранилища не даёт приложению перезаписать непрочитанные данные значениями по умолчанию.
- «Сегодня», план повторения и оценка памяти обновляются при возвращении на экран и смене календарного дня.
- «Настройки → Эксперименты» сохраняет общую заметку и историю отдельных запусков с датами начала, остановки и заметкой к каждому запуску. Эксперимент «Скрыть повторение на сегодня» убирает блок только на время запуска; остановка возвращает его. Эксперименты входят в резервную копию и переживают сброс статистики. По умолчанию они выключены.

## Проверка перед выпуском

`npm run check` проверяет типы приложения и прокси, книгу, данные, алгоритмы и обработку отказов. `npm run check:ui` проверяет взаимодействия на локальном тестовом бандле, включая оба вида двойных рамок, перезапуск и ошибки хранилища. Android/iOS требуют также экспорта Hermes и проверки установленного приложения на устройстве.

Подробные результаты текущего ревью: [аудит от 23 октября 2026](audit-2026-10-23.md).
