# Повторное ревью Papanda — 20 октября 2026

Подготовлен выпуск 1.2.1. Ревью выполнено поверх текущих локальных изменений
приложения, включая мастерскую предложений и счётчик показов.

## Исправленные проблемы

| Проблема | Исправление |
| --- | --- |
| Возврат к карточке восстанавливал весь старый объект прогресса: исчезали последующие правки, избранное и показы, расходясь с дневной статистикой | Отмена меняет только оценку знания затронутого языка; более поздний отличающийся ответ сохраняется. Фактические показы остаются в истории |
| Импорт и сброс оставляли смонтированным экран с прежней очередью и историей отмены | Неперсистентная ревизия прогресса пересоздаёт учебные экраны и словарь, сохраняя навигацию и сообщение результата импорта в настройках |
| Первый показ импортированного custom word мог начинать счётчики с нуля | Единое получение эффективного прогресса учитывает исходное пользовательское определение и сохранённые переопределения |
| Оценка одного языка могла пометить всё слово выученным | Общая отметка проверяет знание всех активных языков |
| Смена избранного стирала набранный черновик личной ассоциации | Синхронизация карточки меняет поле только при изменении самой сохранённой ассоциации; возврат также сохраняет черновик |
| После изучения последнего слова нельзя было отменить отметку | Пустой экран предоставляет кнопку возврата к предыдущему слову |
| Выбор очередной карточки мог сразу повторять текущую при наличии других слов | Чистая функция выбора исключает немедленный повтор, сохраняя веса памяти и возможность повторять единственное доступное слово |
| Смена языков на скрытой вкладке могла записать показ; история сохраняла оценки прежнего набора языков | Выбор карточки выполняется при видимом экране; смена языков очищает историю сессии |
| Итог последнего повторения исчезал при переходе на пустую следующую очередь | Новая очередь создаётся после закрытия результата |
| Поиск слов в предложении смешивал переводы и английские ключи: например, итальянское `sale` могло совпасть с английским `sale` | Индекс форм строится только для изучаемого языка |
| «Отменить запрос» для новых серий в мастерской не останавливало генерацию | Сигнал владельца запроса доходит до транспорта и связан с глобальной отменой. Отмена мастерской не отменяет независимую генерацию тренажёра |

Рефакторинг вынес выбор карточки, построение языкового индекса и правила отмены
оценки/получения прогресса в чистые функции. Общий механизм генерации сохранил
объединение одинаковых фоновых запросов, добавив отдельное владение запросами
мастерской. Формат резервной копии не изменён.

## Ограничения и зависимости

Актуальный `npm audit` сообщает 26 предупреждений (21 high, 5 moderate,
0 critical). Они происходят от трёх известных advisory: `braces`,
`node-forge`, `sprintf-js`, включая зависимые пакеты. Существующие локальные
патчи для этих случаев сохранены; регрессионные тесты проверяют их действие.
Чистый audit не заявляется. Автоматически предложенный откат Expo до 44 или
переход на несовместимую ветку React Native не применялся.

Проверка физического Android-устройства, системной отправки backup-файла и
лингвистическая экспертиза всех слов/ответов ИИ не выполнялись. Публичный
AI-прокси по-прежнему использует квоты по установке и общий бюджет;
идентификатор установки не заменяет аутентификацию. Worker в этом выпуске
не изменялся и не развёртывался.
