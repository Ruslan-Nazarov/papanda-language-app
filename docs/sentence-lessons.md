# Эксперимент: занятия по 5 предложений

Включение: **Настройки → Эксперименты → Занятия по 5 предложений → Запустить эксперимент**. По умолчанию выключен. Использует общий механизм дат, заметок и истории запусков экспериментов.

При включении вкладка разбора открывает короткое занятие на выбранном активном языке. Свободный тренажёр, мастерская и свои тексты доступны кнопкой «Свободный разбор и свои тексты». Переход к конкретному примеру из словаря или книги открывает обычный тренажёр.

## Занятие

- Пять разных предложений: два места для разминки/повторения, объяснение с подсказками, самостоятельная практика и другой пример для проверки. После завершения можно закончить или взять ещё три предложения.
- Одна цель: основа → признаки → дополнение → обстоятельства → несколько основ. В каждом упражнении сохраняется поиск основы. Темы без достаточного количества примеров пока не предлагаются. Переход требует минимум двух оценённых ответов по цели и не менее 80% самостоятельных ответов в двух занятиях в разные календарные дни. Это начальные параметры эксперимента, а не доказанная норма или оценка уровня языка.
- Первые два места занимают доступные повторения, в первую очередь трудные. Помощь, ошибка или пропуск возвращают пример примерно через день; самостоятельный успех расширяет интервал: 1, 3, 7, 14 дней. Повторения входят в объём занятия, долг за пропущенные дни не увеличивает занятие. В примерах используются локальный каталог и встроенный резерв, отдельного запроса ИИ нет.
- Завершённый разбор, помощь, ошибки, пропуски и спорные ответы различаются. Пропуск позволяет закончить занятие, но не даёт успешного результата. Спорный ответ исключается из оценки; карточка с ним не планируется для повторения.
- Сохраняются снимки предложений, позиция, выбранные слова, открытый перевод, подсказки и проверенные ответы. Перезапуск приложения, остановка эксперимента и обновление ИИ-кеша не заменяют открытое упражнение. Повторное включение продолжает сохранённое занятие.
- Прогресс раздельный по языкам и входит в резервную копию. Хранятся до 60 итогов (включая подтверждения освоенных тем) и 20 карточек повторения на язык. Удаление старых итогов не закрывает освоенные темы. Сброс статистики очищает прогресс занятий вместе с результатами разбора; история запусков эксперимента сохраняется. Старые резервные копии не включают эксперимент автоматически.

## Проверки

Алгоритмы, переключение, восстановление, резервные копии и повреждённые данные: `npx tsx --test tests/sentenceLessons.test.ts`. Обязательные проверки проекта: `npm run check`.

На тестовом web-экспорте: `node scripts/smoke-sentence-lessons.cjs` (папка по умолчанию `dist-audit`, переопределяется `SMOKE_BUNDLE_DIR`). Проверяет включение из настроек, сохранение проверенного шага после перезагрузки, остановку и повторный запуск, подсказку, спорный ответ, итог пяти предложений, дополнительные три, свободный режим и ширину 320px. Сценарий включён в `npm run check:ui`.
