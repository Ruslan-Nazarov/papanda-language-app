# Ревью Papanda 1.3.1 — 23 октября 2026

Проверка выполнена от `2d21478` (`main`) с восстановлением двойных рамок из предыдущего этапа работы. Цель — подготовить устойчивую версию для длительного использования, сохранив методику и пользовательские функции. После завершения ревью версия 1.3.1 отправлена в EAS по запросу пользователя: **[Android build 25](https://expo.dev/accounts/runaz/projects/papanda-app/builds/350eb824-eb0c-4a7c-b1bd-e451af85e05d)**, профиль `preview`, APK, существующий ключ подписи. EAS подтвердил приём 23 октября 2026 в 04:58 UTC; на этот момент статус `NEW`. Worker не развёртывался.

## Объём

Проверены навигация и жизненный цикл экранов, два вида тренажёра, словарь и редактирование, туры слов, тренировка и отмена ответов, мастерская, книга, статистика, хранение и миграции, импорт/экспорт, генерация и отмена ИИ-запросов, разбор ответов моделей, серверная валидация и квоты, зависимости, CI и конфигурация сборки. История последних изменений сверена с ранее согласованными изменениями интерфейса.

Рефакторинг сосредоточен на местах с воспроизводимыми рисками: единая карточка для двух видов тренажёра, общий механизм записи хранилищ, общий путь применения и отката импорта, явное построение очереди предложений, единое завершение тренировки, часы для статистики и выбор кандидата словарной проверки. Статические словари, тексты книги, порядок разбора и формулы оценки памяти не переписывались.

Это вывод по истории и тестам, а не заявление о полном совпадении со всеми когда-либо существовавшими версиями.

## Зависимости и границы проверки

Актуальный `npm audit`: основное приложение — **21 high, 0 moderate, 0 critical**; Worker — **0**. Все 21 предупреждение относятся к двум причинам и их зависимым пакетам: `braces` ([GHSA-vfj7-8cjw-p6xm](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)) и `node-forge` ([GHSA-86w9-cpqp-85rv](https://github.com/advisories/GHSA-86w9-cpqp-85rv)). Существующие локальные защитные патчи сохранены и проверены тестами. Они не превращают результат `npm audit` в нулевой. Предлагаемые npm несовместимые переходы Expo/React Native не применялись.

UI проверяется на web-бандле в отдельных браузерных профилях; внешние запросы перехватываются, ответы ИИ моделируются. Экспорт Android/iOS подтверждает компиляцию JavaScript и Hermes, но не заменяет испытание установленного APK. Физический телефон, системная отправка/выбор файлов и реальные ответы платных ИИ в этом ревью не проверялись.

Полное внезапное отключение устройства между записями двух хранилищ не является транзакцией: для восстановления остаётся отдельная точка до импорта. При постоянном повреждении JSON приложение сохраняет исходные байты и показывает ошибку чтения; автоматического восстановления повреждённого содержимого нет. Публичный ИИ-прокси сохраняет прежнюю модель доступа: install ID ограничивает использование, но не является аутентификацией; общий бюджет обязателен.

Версия исходников — **1.3.1**. Номер нативной сборки управляется EAS; при отправке EAS повысил его с 24 до **25**. Облачное окружение `preview` содержит рабочий адрес ИИ-прокси; тестовый `smoke.invalid` не используется. Перед длительным использованием остаётся дождаться завершения сборки, установить APK и проверить на целевом телефоне обновление поверх текущей версии, сохранность реального прогресса, системные диалоги файлов, сворачивание/возврат и работу при плохом соединении.
