# Ревью Papanda 1.3.1 — 1 ноября 2026

Ревью охватывает приложение, Cloudflare Worker, сохранение и импорт прогресса,
очереди тренировок, расписание повторений, морфемы, статистику разборов,
интерфейс и подготовку EAS. В сборку включаются текущие локальные изменения
владельца: фиксированные туры слов, новое расписание, статистика предложений,
изменения настроек и навигации. Они не откатывались.

## Исправления

- Ручная ИИ-проверка могла записать запоздалый вердикт после изменения слова
  или восстановления профиля. Теперь перед записью сверяются словарный ключ,
  русский перевод, контекст, проверенные переводы и ревизия прогресса.
  Отмена экрана и общая отмена при импорте, сбросе и смене языков передаются
  в запрос. Ручная и фоновая проверки используют общее представление исходных данных.
- В редакторе результат проверки относился к окну, а не к конкретному тексту:
  после проверки можно было изменить перевод и сохранить прежний вердикт.
  Теперь результат связан с проверенным черновиком; изменение полей, закрытие
  или смена слова отменяют запрос. Запоздалый ответ не появляется в другом
  открытии редактора. Действующий вердикт сохраняется только вместе с теми
  данными, которые проверены. Проверка черновика также получает контекст слова.
- У немецкого причастия с открывающей кавычкой (`«Gekauft!»`) приставка `ge`
  не распознавалась при назначении цветов. Теперь кавычка не мешает выделить
  приставку и оставить корень `kauf` без цвета окончания; написание сохраняется.
- EAS CLI проверяет исключение `.git` как путь без завершающего слеша.
  Прежнее правило `/.git/` оставляло историю в копии проекта. Правило заменено
  на `/.git`, исключение подтверждено повторной инспекцией.
- В текущем проекте EAS удалённый Android-счётчик был ниже предыдущего
  опубликованного APK: запуск получил `versionCode 16`, тогда как APK от
  28 октября имеет `28` и тот же `com.papanda.app`. Первый запуск
  `450cc2e5-3bb5-4376-90d8-4688b9232a09` отменён. Счётчик поднят до 28,
  повторная сборка с `autoIncrement` получила 29. Проверка установленного
  APK и совместимости подписи на устройстве не выполнялась.
- UI-тесты книги и тренажёра содержали ожидания удалённых элементов:
  перехода в практику из книги, поля ассоциации и отдельного переключателя
  перевода. Проверки согласованы с действующим контрактом: единая кнопка
  разбора, перевод после раскрытия всех блоков, затем повтор; последний переход
  завершает тур. Сохранены проверки геометрии и обеих двойных рамок.

Пересоздание тренировок при импорте и сбросе уже реализовано ключом
`progressRevision` в навигации. Дополнительная дублирующая логика не добавлялась.

В приложении обновлены 17 пакетов в пределах существующих диапазонов:

сохранены. Эти предупреждения остаются ограничением; нулевой общий аудит
не заявляется.

## Проверки

- `npm run check`: книга актуальна, типы приложения и Worker проверены,
  **278 тестов, 0 ошибок**. Добавлены 8 проверок ручного ИИ-аудита:
  устаревшие ответы, отмена, импорт, сброс, смена языков и сохранение чужих правок.
- Дополнена проверка немецкого причастия с кавычками; UI-сценарий редактора
  проверяет изменение черновика после проверки, изменение во время запроса,
  закрытие/повторное открытие и сохранение актуального вердикта.
- Все **17 UI-сценариев** прошли на бандле `dist/review-2026-11-01`:
  вводный экран, основные вкладки, мастерская, 66 материалов книги, повтор,
  тренажёр, управление генерацией с замедлением CPU ×4, редактор слов,
  туры и очереди, статистика, жизненный цикл, заметки, обсуждение,
  эксперименты, занятия по предложениям и дизайн-система.
  Прогон завершён по частям: после исправления устаревших ожиданий повторялись
  затронутые сценарии. Контроль генерации использует независимые примеры,
  явный размер тура и проверяет сохранение карточки/позиции при вытеснении кеша.
- Web, Android и iOS экспортированы; мобильные бандлы скомпилированы Hermes.
  В трёх релизных бандлах подтверждён рабочий URL прокси, `smoke.invalid` отсутствует.
- `npm run build --prefix gemini-proxy`: dry-run успешен после обновления инструментов.
- Рабочий `/health` вернул `{"ok":true}`. Генерация и качество живых ответов
  провайдера этим запросом не проверяются.
- Инспекция архива EAS подтвердила включение новых исходников и отсутствие
  файлов `.git`, `.env`, `.npmrc`, ключей подписи, тестовых экспортов и кешей.
- `git diff --check` и синтаксические проверки изменённых UI-скриптов прошли.

Окончательная инспекция сверила SHA-256 восьми ключевых файлов с рабочей копией,
включая lock-файл, исправления зависимостей и новые модули; расхождений нет.
