# Аудит и рефакторинг Papanda — 24 сентября 2026

Проверен рабочий проект `papanda-app`: приложение Expo/React Native, состояние,
сервисы AI, импорт/экспорт, тренировки, статистика, Cloudflare Worker,
зависимости, тесты и сборочные настройки. На старте были незакоммиченные
изменения в 13 файлах и пользовательский скрипт `scripts/demo_sentences.ts`;
они учитывались как исходное состояние. Соседние резервные копии не изменялись.
Контент `book/` не подвергался лингвистической или редакционной проверке.

## Исправленные проблемы

| Приоритет | Проблема и последствия | Исправление / проверка |
|---|---|---|
| P1 | Произвольный объект принимался как backup; некорректные вложенные данные могли заменить прогресс и сломать экраны | `progressValidation.ts`: проверка вложенных полей перед единственным атомарным обновлением; неподдерживаемая версия backup отклоняется; отрицательные/нечисловые счётчики запрещены |
| P1 | UI мог менять store до завершения асинхронного чтения сохранённых данных | Отдельное неперсистентное состояние загрузки, блокировка UI до успешного чтения; ошибочные данные не перезаписываются; есть повторная загрузка |
| P1 | `updateWordDetails` менял `eng`, одновременно служащий ключом прогресса | Ключ стабилен; изменения отображения применяются через единый `applyWordProgress`; регрессия rename → обучение → экспорт/импорт |
| P1 | Сброс статистики удалял переводы и ассоциации встроенных слов | Удаляются статистика и отсрочки; пользовательское содержимое, избранное и AI-вердикты сохраняются |

| P1 | Устаревший Markdown-парсер обрабатывал недоверенный AI-текст | Override `markdown-it ^14.2.0`, lockfile разрешён в 14.3.2; проверен экспорт всех платформ |
| P2 | Изменённое встроенное предложение после перезапуска появлялось вместе с исходным | Общая проекция предложений с приоритетом пользовательской версии по ID |

| P2 | Ключ вида `user:kz:...` показывался и считался переводом на английский | Разделены ключ и видимое значение; дефисы/апострофы внутри леммы сохраняются |
| P2 | Дневная статистика писалась в UTC, а график использовал местную дату | Общий `localDateKey`; временные метки остаются ISO/UTC; старые агрегаты не передатированы |
| P2 | Снижение размера тренировки могло оставить больше выученных слотов, чем общий размер | Ограничения в store и функции построения очереди; тест верхней границы |
| P2 | Сортировка очереди вызывала `Math.random()` внутри comparator; смена настроек сохраняла старый score | Случайная поправка вычисляется один раз, Fisher–Yates shuffle, сброс score при создании очереди |

## Архитектура и уборка

- `store/progressTypes.ts` — контракт сохраняемых данных, defaults, выбор полей.
- `store/progressValidation.ts` — граница доверия для сохранённых данных и backup.
- `store/catalog.ts` — статическая база и чистое восстановление слов/предложений.
- `store/useStore.ts` — действия; повторное применение переводов и прогресса удалено.
- `utils/workout.ts` — построение тренировочной очереди независимо от React.
- `hooks/usePronunciation.ts` — общий жизненный цикл AI-модалки.
- `gemini-proxy/src/requestValidation.ts` и `quota.ts` — отдельные границы запроса и квот.
- Экраны подписаны на используемые поля через `useShallow`, а не на весь store.
- Удалены дубли парсинга статистики, неиспользуемые `asToken`,
  `getDictionaryCandidates`, `Language`, `WordTranslation`; убраны нетипизированные
  снимки истории и ненужное JSON-клонирование immutable progress.
- Генератор ID предложений вынесен из prompt-модуля, исключены коллизии ID
  нескольких генераций в одной миллисекунде.
- Добавлены `npm run check`, тесты Worker и workflow CI. Кэши и результаты
  локальной проверки исключены из Git.

## Проверка и границы результата

- Исходно: 36 тестов, type-check приложения проходил.
- После изменений: 64 теста, type-check приложения и Worker проходят.
- Проверены 2609 слов и 170 seed-предложений: дубликатов ключей слов и ID
  предложений в поставляемых данных не найдено.
- `expo export --platform all`: собраны web, Android и iOS JS/Hermes bundles.
  Это не сборка APK/IPA.
- `wrangler deploy --dry-run`: Worker собирается с binding `QUOTA`.
- Headless web smoke: старт и hydration, пять вкладок, перезагрузка,
  сохранение повреждённого хранилища без перезаписи и отсутствие
  необработанных JS-исключений; внешние AI-запросы заблокированы.
- CI добавлен, но удалённый запуск GitHub Actions в этой работе не выполнялся.
- Не выполнялись публикация Worker, запись в production, реальные платные
  вызовы AI, Android/iOS device-тесты или лингвистическая проверка датасета.

## Остаточные риски и следующие работы

1. **P1 — зависимости Expo:** 19 предупреждений остаются открытыми; нужна
   отдельная миграция SDK с native-проверками.
2. **P2 — доступ к AI:** install ID клиент может сменить. Durable Object
   ограничивает общий расход запросов, но не устанавливает личность клиента.
   Для закрытого сервиса нужна серверная авторизация/аттестация и бюджет
   провайдера. Один допущенный запрос может вызвать два provider-вызова.
3. **P2 — rollout квот:** первый deploy создаст новую SQLite namespace и
   обнулит счётчики относительно прежнего KV. Старый KV не удалён.
   Бюджеты проверены unit-тестами, но нагрузочная проверка реального DO
   на Cloudflare не выполнялась.
4. **P2 — долгие AI-задачи:** совпадающие запросы объединяются, но нет
   пользовательской отмены всего процесса нескольких раундов/повторов.
   Импорт или смена настроек во время генерации требует отдельного сценария
   интеграционного тестирования.
5. **P2 — документация приватности:** `docs/privacy-policy.md` описывает только
   Gemini, тогда как код может отправлять данные в Cerebras/Groq и делать
   фоновые запросы. Нужны фактически корректное описание и синхронизация
   опубликованной политики; юридическая оценка не входила в аудит.
6. **P3 — UI:** крупный `SentenceTrainerScreen` всё ещё совмещает редактор,
   рендер разметки и управление очередью. Следующий этап — выделение редактора
   и отдельного контроллера с interaction-тестами на устройстве. Навигация
   ещё содержит `useNavigation<any>`.
7. **P3 — данные:** старые дневные UTC-агрегаты нельзя достоверно переразложить
   по местным дням без истории событий; исторические значения сохранены.
   Уже потерянный прежней версией прогресс восстановить этим патчем нельзя.
