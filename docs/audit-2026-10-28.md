# Ревью Papanda 1.3.1 — 28 октября 2026

Проверены правки со скриншотов и перенос дизайн-системы papanda 0.7.167 на экран
«Слова». Прежняя работа сохранена отдельным коммитом `35f16a7`, точечные исправления
— `f0a36b9`, первый экран — `714001d`. Оформление других экранов ожидает оценки
владельца; изменения компактных действий сохраняют запрошенную область правок.

## Исправления и рефакторинг

После увеличения кнопок панели слова до 44 px у них оставался `hitSlop` 10 px:
дополнительные области могли пересекаться с соседними действиями. Расширение
убрано у уже достаточно крупных кнопок. Возвращена прежняя обработка клавиатуры
Android, чтобы изменение оформления не меняло её поведение без проверки устройства.

Геометрия компактных действий вынесена в `CompactAction`: поверхность от 32 px,
отдельная область нажатия от 44 px, общий фокус. Компонент используется кнопкой
составления предложения, переключателем перевода и действиями окна формы слова.
Сохранены подписи, disabled/selected, переходы, шаги разбора и формат прогресса.
Удалены оставшиеся неиспользуемые стили прежних значков.

Четыре UI-скрипта не учитывали `SMOKE_BUNDLE_DIR` и могли читать прежний
`dist-audit`. Теперь весь прогон использует выбранный бандл. Проверки свайпов
привязаны к слову, используют сенсорный жест и сохраняют режим эмуляции при
смене ширины. Тестовая инициализация не обращается к localStorage пустого
документа; профиль жизненного цикла подставляется до гидратации, чтобы отложенная
запись открытого приложения не заменяла фикстуру.

Из архива EAS исключён локальный `.npmrc` с Windows-путём к кэшу: облачный
Linux-сборщик использует своё окружение. В инспекции архива подтверждены новые
компоненты, исходный tokens.json и Doodle PNG; .env, локальный npm-конфиг,
файлы кэшей, тестов и ключей подписи в отправляемые исходники не попадают.

## Проверки

- `npm run check`: книга актуальна, типы приложения и Worker проверены,
  **248 тестов, 0 ошибок**.
- Все **16 UI-сценариев** прошли на одном актуальном бандле `dist/design-refactor`.
  Первые четыре прошли в основном прогоне; после исправлений подготовки тестов
  отдельно завершены оставшиеся сценарии. Проверены разбор, мастерская, книга,
  словарь, тренировка, сохранение/восстановление, статистика, заметки, обсуждение,
  эксперименты, занятия и первый экран дизайн-системы.
- Экран «Слова»: 320/390/1440 px, шрифты, длинные подписи, текст ×1,5,
  фокус, компактные действия с полноценной областью нажатия, ввод ассоциации,
  пустое состояние, ожидание, 402 и повтор.
- Android экспортирован с Hermes после очистки Metro-кэша и с рабочим
  `EXPO_PUBLIC_GEMINI_PROXY_URL`. В полученном HBC есть рабочий адрес прокси,
  `smoke.invalid` отсутствует.
- Рабочий `/health` вернул HTTP 200. Минимальный запрос и объяснение частицы
  «ме» с лимитом ответа 4096 и бюджетом рассуждения 512 также вернули HTTP 200
  с непустым ответом. Ошибка 402 в этих запросах не воспроизвелась. Эти проверки
  не подтверждают качество объяснений для всех слов и языков.
- `git diff --check` и синтаксические проверки изменённых UI-скриптов прошли.

Физический Android/iOS, экранная клавиатура и VoiceOver/TalkBack не проверялись.
Прокси не развёртывался: приложение совместимо с его прежним ответом 402 и
показывает понятное сообщение, если ограничение повторится.
