# papanda — как установить (Android)

Приложение пока не в Google Play, ставится напрямую файлом. Занимает 2 минуты.

## Установка

1. Открой на телефоне ссылку, которую тебе прислали, и нажми **Download / Скачать** —
   скачается файл `papanda.apk`.
2. Открой скачанный файл (из шторки уведомлений или в «Загрузках»).
3. Android спросит разрешение ставить приложения из этого источника —
   **Настройки → «Разрешить из этого источника»**, вернись назад.
4. Появится предупреждение **Play Protect** («Неизвестное приложение…»):
   нажми **Подробнее → Всё равно установить**.
   *(Если кнопки нет: Play Маркет → значок профиля → Play Защита → шестерёнка →
   выключи «Сканировать приложения», поставь papanda, потом можешь включить обратно.)*
5. Готово, иконка papanda появится в списке приложений.

Это одноразовые шаги — обновления будут ставиться поверх без плясок.

## Что важно знать

- Интерфейс на русском, тема только светлая.
- Первый экран — короткое интро (3 слайда), потом основное приложение.
- Весь прогресс хранится **на телефоне**. Перед удалением/переустановкой сделай
  **Настройки → Экспортировать прогресс** и сохрани файл.
- Часть примеров-предложений генерирует ИИ. Иногда он недоступен — тогда показываются
  заранее заготовленные предложения, это нормально.
