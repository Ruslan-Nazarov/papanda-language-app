## Границы первого этапа

Пилот — **«Слова» (`WordTriplesScreen`)**, включая его пустые состояния,
завершение тура и статистику слова. После оценки владельцем можно переносить
оформление на остальные экраны. Общая палитра `src/constants/theme.ts`,
навигация, редактор словаря и экран произношения пока сохраняют прежнее оформление.
На тренажёре и в объяснении формы сделаны только запрошенные компактные действия;
в тренировке перенесён предыдущий ответ и сокращена подпись счётчика показов.

Эксперимент «Скрыть повторение на сегодня» уже существует:
«Настройки → Эксперименты». Он скрывает блок на время запуска; остановка
возвращает блок. Этот этап сохраняет его настройки и историю.

## Соответствие ролей React Native

| Роль системы | Реализация |
|---|---|
| Токены | `src/design/papanda.ts` импортирует исходный `tokens.json` |
| Фон и поверхности | `canvas` #FFF5EC, белая карточка, `surfaceSubtle` для языковых строк |
| Основное действие | «✓ Выучено»: #F2994A, тёмная подпись #1E293B, радиус 12, высота ≥44 |
| Компактное действие | `CompactAction`: поверхность от 32 px и отдельная область нажатия ≥44 px; используется в словах, переводе и окне формы |
| Карточка | Радиус 24, мягкая тень, мобильный внутренний отступ 16 |
| Поле | Inter 16, постоянная подпись «Личная ассоциация», белый фон, радиус 12, различимый фокус |
| Фокус действий | `PapandaAction`: контур #9A4D13, 2 px с отступом 3; положение содержимого не меняется |
| Типографика | `usePapandaFonts`: Inter 400/500/600/700 и Outfit 500/600 из локальных npm-ассетов; при сбое загрузки — системные шрифты |
| Значки | `PapandaIcon`: производные PNG исходных Doodle, без изменения геометрии, цвет по роли |
| Состояния | Пустое состояние и завершение тура подписаны; сохранённая ассоциация отмечена текстом; отказ ИИ показывается сообщением с доступным повтором |

Шрифты доставляются вместе с приложением через зафиксированные `package-lock.json`
пакеты `@expo-google-fonts/inter` 0.4.2, `@expo-google-fonts/outfit` 0.4.3 и
`expo-font` ~14.0.12 (Expo SDK 54). Лицензии шрифтов OFL-1.1 поставляются
в соответствующих пакетах; их копии сохранены в `assets/font-licenses/`.
Глифы, отсутствующие в гарнитуре, используют системную
замену. В Outfit нет кириллицы: русские заголовки используют Inter, латинские
учебные слова — Outfit; казахский текст — Inter с системной заменой отсутствующих
глифов. Веб-заголовки явно включают Inter и sans-serif в цепочку замены.
Масштабирование текста React Native не отключается.

Doodle: Khushmeen Sidhu, CC0-1.0, источник `theJian/doodle-icons`, ревизия
`bd2b5ea27202dca3f22e7ae1ca16649e4420de9e`. Сохранены исходные
`icons/README.md` и `icons/manifest.json`. Прозрачные PNG 96×96 в
`assets/papanda-doodle/` создаются из SVG командой
`node scripts/build-design-icons.cjs` (нужен доступный модуль `sharp`).
`provenance.json` хранит хэши входных SVG. Это адаптация к нативному стеку,
без загрузки другого набора значков.

## Локальные расширения

- Учебная колонка ограничена 560 px на широком экране; на телефоне занимает
  доступную ширину. Карточки языков и ассоциация идут в обычном потоке с прокруткой.
- Учебное слово — 24–28 px; языковые флаги остаются предметными обозначениями.
  Метаданные и компактная панель карточки используют 12 px, действия — 14–16 px.
- Зелёный обозначает результат обучения и сохранённую ассоциацию. Основная
  кнопка остаётся оранжевой; второй брендовый акцент не вводится.
- ИИ-ошибка 402 получает понятную подпись и не запускает автоматические
  бесполезные повторы. Прокси сохраняет попытку резервного провайдера.
  Изменение обработки ошибки не исправляет биллинг или конфигурацию рабочего сервиса.

Общие правила сначала обсуждаются в исходной системе papanda. Особенности
учебного сценария фиксируются здесь как локальные расширения.
