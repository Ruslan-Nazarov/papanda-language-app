# Doodle Icons

Icons by Khushmeen Sidhu: https://khushmeen.com/icons.html
Icons are dedicated to the public domain under CC0 1.0 Universal:
https://creativecommons.org/publicdomain/zero/1.0/legalcode

Original SVGs are bundled locally from theJian/doodle-icons at the pinned commit
in manifest.json. The manifest records the original path and SHA-256 for each
application meaning. Geometry is unchanged. CSS supplies currentColor and size;
the original cross is rotated for the add control. Repeated meanings deliberately
share artwork. The manifest makes these choices explicit.
